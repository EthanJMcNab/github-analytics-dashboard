# Code of Conduct

## Our Standards

This project should be a respectful, constructive space for learning and collaboration.

Expected behaviour includes:

- using welcoming and inclusive language
- respecting different viewpoints and experience levels
- giving and receiving feedback constructively
- focusing criticism on ideas and implementation, not people

Unacceptable behaviour includes harassment, personal attacks, discriminatory language, or publishing private information without permission.

## Enforcement

Project maintainers may remove comments, issues, pull requests, or contributions that do not meet these standards. Serious or repeated violations may result in being blocked from participating in the project.

## Reporting

If you see behaviour that violates this code, contact the project maintainer with relevant context and links where possible.
