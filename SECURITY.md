# Security Policy

## Supported Versions

This portfolio project is maintained from the `main` branch. Security fixes are applied to the latest version of the application.

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue with exploit details. Instead, contact Ethan J McNab directly with:

- a short description of the issue
- steps to reproduce it
- the affected area of the application
- any suggested mitigation

I will acknowledge valid reports as soon as practical and prioritize fixes based on severity and user impact.

## Secrets

API keys and tokens must stay in local environment files such as `.env.local` or deployment environment variables. Do not commit secrets to the repository.
